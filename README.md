# 📦 Distributed File Sorter

Проект по распределённой сортировке большого текстового файла с использованием клиент-серверной архитектуры и нескольких вычислительных узлов в локальной сети.

## 📌 Описание

Данный проект реализует систему, в которой клиент отправляет большой файл на сервер. Сервер разбивает файл на части и распределяет их между несколькими удалёнными узлами. Каждый узел выполняет локальную сортировку своей части и отправляет результат обратно. Затем сервер выполняет финальное объединение и сортировку, и отправляет отсортированный результат клиенту.

Поддерживается корректное деление файла даже в случае, если он состоит из одной длинной строки слов.

---

## 🛠️ Архитектура

```
Клиент → Сервер → Узлы
          ↓         ↑
     Деление    Сортировка
     файла →    → частей
          ↓         ↓
     Объединение и финальная сортировка
          ↓
     Отправка результата клиенту
```

---

## ⚙️ Технологии

- Язык: **C**
- Протокол: **TCP/IP**
- Формат данных: **Plain text**
- Сетевое взаимодействие: `socket()`, `bind()`, `connect()`, `send()`, `recv()`
- Разделение файла: на границах **слов**, без порчи данных

## 🚀 Запуск

### Сервер
1. Компилируйте `server.c`:
   ```bash
   gcc server.c -o server
   ```
2. Запустите сервер:
   ```bash
   ./server
   ```

### Узлы
1. На каждом узле скомпилируйте `node.c`:
   ```bash
   gcc node.c -o node
   ```
2. Запустите на нужном порту:
   ```bash
   ./node 9091  # или 9092, 9093 и т.д.
   ```

### Клиент
1. Скомпилируйте `client.c`:
   ```bash
   gcc client.c -o client
   ```
2. Отправьте файл:
   ```bash
   ./client path/to/file.txt
   ```

## 🧠 Особенности

- Деление файла по **границам слов** — без обрыва данных
- Простая интеграция новых узлов — измените IP и порт в `server.c`
- Обратная отправка клиенту после полной сортировки
